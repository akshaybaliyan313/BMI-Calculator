# ⚖️ BMI Calculator

A simple, responsive BMI calculator built with HTML, CSS and vanilla JavaScript.

## Features

- Calculates BMI from height (cm) and weight (kg)
- Shows category: Underweight, Normal, Overweight or Obese
- Colour-coded scale highlights your result
- Input validation with error messages
- Press Enter to calculate, Reset to clear
- Works on desktop and mobile

## Formula

```
BMI = Weight (kg) / (Height (m) × Height (m))
```

| BMI         | Category    |
|-------------|-------------|
| Below 18.5  | Underweight |
| 18.5 - 24.9 | Normal      |
| 25 - 29.9   | Overweight  |
| 30+         | Obese       |
